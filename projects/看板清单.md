# GitHub Projects 看板清单

## 为什么是这些内容

`README.md` 是**介绍性文档**，本身不含任务项。而 GitHub Projects 是**看板/任务视图**，卡片必须可执行、可关闭。

因此本清单把 README 中的三张事实表（站点结构 15 行 / 分析引擎 7 行 / 目录结构）**转写为可逐项核对的卡片**，每张卡片附验收标准。核对通过即关闭；发现不符则转为修复任务。

---

## 建议的看板列

| 列 | 含义 |
|---|---|
| `Todo` | 尚未核对 |
| `In Progress` | 核对中 / 已发现不符、正在修 |
| `Blocked` | 阻塞（如依赖上游数据批次） |
| `Done` | 核对通过或已修复 |

## 使用方式

1. 在仓库 **Projects** 标签页新建一个 Board（或 Table）视图；
2. 按上表逐条新建卡片，卡片正文填入「验收标准」与「来源」；
3. 建议给 A/B/C/D 四组各加一个标签（`page` / `engine` / `docs` / `infra`），便于筛选；
4. 核对通过后移入 `Done`。

> 若要批量建 issue：可把每行整理为一条 issue 标题 + 验收标准正文，再在 Projects 中批量导入。
